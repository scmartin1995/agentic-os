# Skills

How to do a kind of task, written down so any chat gets it right first time.
Facts about you and your projects live in project notes. Skills hold the how.

## Learning and upkeep
- [learn](learn/SKILL.md) - turn something we did, a folder or a page into a skill
- [lessons-review](lessons-review/SKILL.md) - save what a chat taught into skills
- [skill-tidy](skill-tidy/SKILL.md) - archive unused skills, merge overlaps
- [model-selection](model-selection/SKILL.md) - cheapest model that fits; when to step up
- [vault-health-check](vault-health-check/SKILL.md) - broken links, orphans, missing headers and index pages

## How skills work
- One folder per skill: SKILL.md, plus optional references/, scripts/, templates/.
- Every skill's name and description loads into every chat, so keep the list short and descriptions tight.
- pinned: true in a skill's frontmatter stops the assistant changing it.
- Archived skills move to _archive/. Nothing is deleted.
