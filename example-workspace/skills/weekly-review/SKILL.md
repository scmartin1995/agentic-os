# Weekly review

1. For each folder in `projects/`, read `README.md`, `notes.md` (this week's dated entries) and `action-items.md`.
2. Read `inbox/notes.md` and `inbox/action-items.md`.
3. Write back a short summary, in this order:
   - **Done this week:** items ticked or notes that say something finished.
   - **Stuck:** open items older than a week, or marked "waiting on".
   - **Next week:** three to five concrete items, most important first.
4. Ask before adding anything to an `action-items.md` file. When the user says yes, add them as `- [ ]` lines.
