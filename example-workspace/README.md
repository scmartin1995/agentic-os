# My workspace

This folder is where the assistant works. It reads these notes to answer you and writes its work back here.
Everything is plain markdown, so any editor (or Obsidian) can open it too.

## Layout

```
README.md              this page; the assistant reads it first
projects/
  <project-name>/      one folder per project
    README.md          what the project is and where it stands
    notes.md           dated notes      -> shown on the Notes page
    action-items.md    checkbox list    -> shown on the Actions page
inbox/
  notes.md             notes that don't belong to a project yet
  action-items.md
skills/
  <skill-name>/SKILL.md   how to do a kind of task, step by step
agent/
  persona.md           the assistant's personality (yours to edit)
  avatar.png           optional picture for the assistant's card
```
